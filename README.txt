SAM IRRIGATION — VERSION HEBDOMADAIRE SIMPLIFIÉE

Cette version remplace les versions précédentes.

MODIFICATIONS
- Suppression complète de la correction manuelle de la pluie passée.
- La pluie passée utilisée est directement celle d’Open-Meteo.
- Suppression des lignes répétitives « Apport 1 », « Apport 2 », etc.
- Le résultat affiche uniquement :
  - nombre d’apports ;
  - dose identique par apport ;
  - volume identique par apport ;
  - durée identique par apport.

LOGIQUE
- Déficit passé depuis le dernier arrosage.
- Besoin prévisionnel brut sur 7 jours.
- Déduction de la pluie efficace prévue.
- Besoin total à programmer sur 7 jours.
- Fractionnement en apports strictement identiques.
- Fréquence choisie par le producteur.

MISE À JOUR GITHUB
1. Décompresse le ZIP.
2. Remplace tous les anciens fichiers et dossiers du dépôt.
3. Envoie :
   - index.html
   - manifest.webmanifest
   - service-worker.js
   - dossier css
   - dossier js
   - dossier assets
4. Clique sur Commit changes.
5. Attends 1 à 2 minutes.
6. Vide le cache ou actualise deux fois.

IMPORTANT
- Les réglages sont stockés localement sur le téléphone.
- Aucun compte utilisateur.
